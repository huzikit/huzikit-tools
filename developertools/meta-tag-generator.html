Frequently Asked Questions

            

              Common questions regarding meta tags, search engine indexing, and
              social preview cards.
            

          


          

            

              
              

                Meta tags communicate vital page context to web crawlers and
                social media algorithms. They define what title and snippet
                appear on Google search results, how shared links appear on
                Facebook or Twitter, and instructions on whether search engines
                should index the URL.
              

            


            

              
              

                The universal standard for high-resolution social cards is
                1200 × 630 pixels (a 1.91:1 aspect ratio). For
                Twitter summary cards with square thumbnails, a 1:1 ratio
                (minimum 300 × 300 pixels) is recommended.
              

            


            

              
              

                Google officially confirmed in 2009 that the
                <meta name="keywords"> tag is not used for
                search ranking. However, other internal search engines,
                directories, and alternative crawlers still evaluate keywords,
                so keeping a focused, comma-separated list remains common
                practice.
              

            


            

              
              

                Social platforms cache link previews for days to save bandwidth.
                You can force Facebook to re-scrape your page using the Facebook
                Sharing Debugger, and verify Twitter cards using Twitter's card
                validator.
              

            


            

              
              

                The canonical link tag (<link rel="canonical" href="...">) specifies the authoritative URL for a page. If a URL is
                accessible via HTTP, HTTPS, or with tracking parameters, the
                canonical tag informs search engines which URL should receive
                ranking credit.
